## Decision Log
Авторизация публикации получена 15.10.2026. Аудитория существующего Site сейчас public, сохраняется. Отдельный домен не нужен. Реальные платежи не разрешены; сохраняем DEMO. Telegram нужен вместо WhatsApp, номер не публикуется. Sites не запускает исходный Python сервер; размещённый цикл перенесён в поддерживаемый Worker. Один ограниченный документ в D1 даёт атомарность резерва/статуса/идемпотентности через CAS без небезопасной имитации транзакций. Все update-инструкции проходят роль и этап на сервере. Винные карточки — советы, без цен/наличия/покупки.

## Discoveries
Исходный recommendation-engine Pivka работает по сценарию, числу людей, бюджету и реальному каталогу. Его объёмы алкоголя и максимизация расхода бюджета не перенесены. Новый подбор не расходует весь бюджет молча и объясняет количества. Порции — настраиваемые кулинарные предположения, не универсальные нормы.

## Outcomes
Проверки backend, ролей, конкуренции резерва, чеков, Telegram и порций описаны в TEST_REPORT.md. Browser QA не выполнена: control-browser отсутствует. Пилот не объявляется готовым к реальным покупкам.
